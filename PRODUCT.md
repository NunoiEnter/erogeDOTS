# erogeDOTS

<!-- impeccable:product-schema 1 -->

## Platform
Linux desktop: NixOS, Niri, and Quickshell (Qt Quick / QML).

## Purpose
A personal desktop whose bar, controls, notifications, launcher and terminal themes share a visual novel identity. The user requested an old school visual novel redesign and fixes to the existing dotfiles.

## Existing capabilities
Five character palettes, a Rust theme picker, generated application configs, quick settings, media controls, Niri keybindings, and a four-terminal larp workspace. These are established by the repository.

## Constraints
Keep the theme-switch workflow and existing desktop actions. Keep generated files out of Git. Preserve local changes to Home Manager's MPD configuration. Existing wallpapers and character names are the source assets; do not invent character artwork or quotes.

## Working assumptions
This is the user's daily desktop, so legibility, keyboard use and predictable controls take priority over decorative motion. No standing design workflow preference has been set.

## Confirmed visual direction
The user chose early-2000s romance visual novels: cream panels, pastel accents, and delicate ornaments. Keep the five existing character identities and wallpaper assets.
